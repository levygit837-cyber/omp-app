# Triage Labels

As skills falam em cinco papéis canônicos de triage. Este arquivo mapeia cada papel para o label do GitHub usado aqui.

| Papel nas skills | String neste repo | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Mantenedor precisa avaliar |
| `needs-info` | `needs-info` | Aguardando mais informação do autor |
| `ready-for-agent` | `ready-for-agent` | Totalmente especificada, pronta para um agente rodar sozinho |
| `ready-for-human` | `ready-for-human` | Exige implementação humana |
| `wontfix` | `wontfix` | Não será feita |

Quando uma skill citar um papel (ex.: "aplique o label de pronta para agente"), use a string correspondente da tabela.
